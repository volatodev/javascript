# Volato — Next.js App Router example

Next.js 15 App Router conformance app generated by `volato init`. The
application imports only source committed under `volato/`; it has no Volato
runtime package dependency.

## Run locally

```bash
cp .env.local.example .env.local
# fill in your DSN
pnpm install
pnpm --filter @volatodev/example-nextjs-app-router dev
```
